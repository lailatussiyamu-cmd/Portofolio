Projects

Every tool here started with a clinical problem I saw with my own eyes.

Data audit

ICU Antibiogram × Guideline Audit

Cross-checked the hospital's empiric antibiotic guideline against ~2,400 clinical isolates from four intensive-care units. Mapped dominant pathogens and resistance patterns per unit and specimen. Only two of eight covered conditions were fully supported by local data — surfaced MRSA at 39–55% and carbapenem-resistant A. baumannii at 79–100%.

Data analysis HTML Chart.js Clinical microbiology
Web platform

SynClinics Live

A synchronized referral network connecting outside hospitals to intensive-care beds. Referring sites submit a patient and required documents through one web form; the receiving unit sees the case before the ambulance arrives. Cut paperwork and phone relay that used to eat into the golden window. 94.2% patient satisfaction and 95% satisfaction among referring hospitals.

Web platform Process design Root-cause analysis
Clinical calculator

PediDrip Live

Weight-based syringe-pump rate calculator for PICU continuous infusions — sedation, vasoactives, and neuromuscular blockers across five dosing-unit systems. Designed around patient safety: no data persists, color appears only when it carries clinical meaning, every screen assumes a two-nurse double check.

HTML CSS JavaScript Netlify
Quality improvement

FOOTSAFE-90

A quality-improvement programme across ICU and PICU, built on a problem that moves quietly: immobilised patients lose ankle function and skin integrity over days nobody is counting. Eligibility screening runs off Excel dashboards, progress is tracked in interactive Chart.js visualisations, documented in a PDCA framework.

Excel Chart.js PDCA QI reporting
